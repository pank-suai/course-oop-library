# Финальные результаты сборки

Рабочий каталог: корень репозитория.

Команда: `./gradlew clean test build --no-daemon`

Результат: BUILD SUCCESSFUL.

Команда выполнила clean, test, assemble, check и build для проекта. XML-отчёты после запуска содержат 35 успешно пройденных тестов: 17 в core и 18 в app; failures, errors и skipped отсутствуют.

Контрольный сценарий:

`./gradlew :core:jvmTest --tests application.ControlScenarioTest --no-daemon`

Результат: BUILD SUCCESSFUL.

При работе Bundled SQLite текущий JDK выводит предупреждение о native access. Оно не блокирует сборку и тестирование.
