# Презентация курсового проекта

Каталог `presentation` содержит единственный авторитетный конвейер защиты на Typst и Polylux:

- `presentation/main.typ` — 15 слайдов в формате 16:9;
- `lib/guap-template.typ` — адаптированный шаблон ГУАП;
- `lib/images/` — официальные фоновые изображения и логотип ГУАП;
- `diagrams/*.puml` и `diagrams/*.svg` — упрощённые крупношрифтовые PlantUML-представления домена и Room для защиты;
- `../docs/images/*.puml` и `../docs/images/*.svg` — полные технические диаграммы отчёта;
- `../docs/images/screen_*_room.png` — снимки текущего русского интерфейса;
- `course-oop-library.pdf` — собранная презентация.

Вся авторская текстовая информация на слайдах дана на русском языке; английские элементы являются техническими идентификаторами проекта. Размер текста шаблона, карточек и упрощённых диаграмм не меньше 28 pt, включая заголовки и номера страниц. Растровые снимки показывают реальный интерфейс приложения в его штатном масштабе.

## Сборка

Из корня репозитория:

```text
typst compile --root . presentation/main.typ presentation/course-oop-library.pdf
```

Фактический результат финальной сборки: 15 слайдов, размер страницы 841.89 × 473.563 pt, то есть 16:9.

## Визуальная проверка

Каждый слайд экспортирован в PNG в `artifacts/presentation-qa/slides/`. Контактный лист находится в `artifacts/presentation-qa/contact-sheet.png`, результаты проверки зафиксированы в `artifacts/presentation-build.txt`. Проверены титульный слайд, все содержательные слайды, диаграммы, снимки интерфейса, таблица 35 тестов и итоговый слайд. Устаревшие параллельные артефакты удалены.
