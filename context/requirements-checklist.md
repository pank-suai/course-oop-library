# Чек-лист требований

| ID | Требование | Планируемое доказательство | Проверка |
|---|---|---|---|
| R01 | Иерархия классов | `core/.../domain`, UML-диаграммы, раздел 2 отчёта | Компиляция + инспекция диаграммы |
| R02 | Не менее 5 классов сущностей | LibraryEntity, Person, Reader, Librarian, Publication, Book, Periodical, Loan, LibraryBranch | Тест и таблица классов в отчёте |
| R03 | Многозначная зависимость | `Loan` связывает Reader и Publication; выборки в сервисе | Интеграционный тест многие-ко-многим |
| R04 | Шаблоны проектирования | Repository, MVVM, LoanPolicy Strategy, Factory, Observer, State, Facade | Отдельные диаграммы + тесты паттернов |
| R05 | Графическое приложение | Compose Desktop `app` | Сборка, контрольный запуск, скриншоты |
| R06 | Запрет web | Удалены JS/WASM targets/resources и Pages deployment | Поиск конфигурации + список Gradle tasks |
| R07 | Три категории классов | сущности в core, управляющие сервисы/ViewModel, интерфейсные Compose-классы | Общая диаграмма и раздел 2 |
| R08 | Диаграммы | `docs/images/*.svg`: сущности, паттерны, общая | Наличие, встраивание и визуальная проверка |
| R09 | Тестирование | JVM unit/integration tests, Room persistence test, сценарий запуска | `./gradlew test` + отчёты |
| R10 | Пояснительная записка | `docs/index.typ`, `docs/report.pdf` | Компиляция Typst + визуальная проверка страниц |
| R11 | Презентация 10–15 слайдов | `presentation/course-oop-library.pptx` | 10–15 слайдов, outline, рендер и визуальный просмотр |
| R12 | Постоянное хранение Room 3 | Room entities/DAO/database/repositories, SQLite-файл | Запись → закрытие → повторное открытие → чтение |
| R13 | Убрать наследие алгоритмического задания | Нет BookCipher/ReaderTicket/варианта 624/самописных структур | Поиск по репозиторию + проверка UI и README |

## Дополнительная проверка сохранённой функциональности

- регистрация, просмотр, поиск и удаление читателей;
- добавление, просмотр, поиск и удаление книг/изданий;
- выдача и возврат экземпляров;
- автоматическое изменение количества доступных экземпляров;
- запрет удаления сущностей с активными связями;
- демонстрационные данные и очистка;
- автоматическая генерация идентификаторов без ручного ввода технических кодов;
- сохранение и восстановление читателей, изданий и выдач после перезапуска.
