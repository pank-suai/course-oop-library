# Область публикации

Пользователь разрешил обновить исходники main для запуска на другом ноутбуке. Источник — переданный ZIP с SHA-256 `f55d74f54e6edf9e78f7b00f4cabbf4019d6e3ef5b46b2b87a1d673c4dd25060`.

`source/project/` перенесён в корень репозитория. Код, ресурсы и build-конфигурация приложения сохраняются точно; presentation меняет только относительные пути `../report/` на `../docs/`. Обновлены README и CI для нового набора UI-тестов. Личные базы, ключи и кеши не включаются. Локальная рабочая папка пользователя не изменяется. Старые записки о проверках и проектировании находятся в history и не считаются текущим одобрением.

Защищённая библиотека docs/lib/gost.typ сохранена побайтно из комплекта. Её унаследованные завершающие пробелы являются отдельным исключением проверки whitespace; авторские файлы очищены.
